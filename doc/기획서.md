# 1주차 개발 기록

## 목표
C++ / glc2d 프로젝트의 기본 개발 환경을 구성하고, 단순 실행 확인에서 끝내지 않고 실제 게임 화면 개발을 시작한다.

## 구현 순서
1. Visual Studio C++ 프로젝트 생성
2. NuGet에서 glc2d 설치
3. glc2d 초기화 및 게임 창 생성
4. Render 함수 연결
5. 테스트 리소스 로드
6. 배경, 플레이어, 목표물 출력
7. 플레이어의 좌우 왕복 애니메이션 추가

## 현재 상태
- 게임 창 생성 가능
- glc2d 렌더링 코드 작성 완료
- 텍스처 로드 / 출력 코드 작성 완료
- 플레이어의 기본 움직임 구현 완료

## 다음 주 계획
- 게임 규칙과 목표 구체화
- 기획서 작성
- 클래스 구조 설계
- 입력 처리와 충돌 처리 추가
