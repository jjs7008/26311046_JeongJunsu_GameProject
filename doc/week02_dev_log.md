# 2주차 개발 기록

## 이번 주 구현
- 1주차 자동 이동을 키보드 입력 방식으로 변경
- Player 클래스를 별도 파일로 분리
- Target 클래스를 추가하고 충돌 시 10점 증가
- Obstacle 클래스를 추가하고 아래로 이동하도록 구현
- 장애물 충돌 시 Life 1 감소
- Enter 입력으로 게임 시작 / 재시작
- 점수 100점, Life 0, 제한 시간에 따라 결과 상태로 전환

## 다음 구현 예정
- 점수 / 남은 시간 / Life 화면 표시
- 시작 화면과 결과 화면 정리
- 효과음 추가
- 장애물 속도와 난이도 조절
